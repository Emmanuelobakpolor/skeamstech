RENDER.COM SETTINGS - YOUR ACKED BACKEND
========================================================================

WHAT YOU NEED TO DO ON RENDER DASHBOARD:

1. CREATE ACCOUNT
   - Go to https://render.com
   - Sign up with GitHub
   - Verify email

2. CREATE POSTGRESQL DATABASE
   - Click: New + > PostgreSQL
   - Name: acked-postgres
   - Database: ackeddb
   - User: ackeddb_user
   - Region: Oregon (or closest)
   - Plan: Free tier
   - SAVE THE CREDENTIALS!

3. CREATE WEB SERVICE
   - Click: New + > Web Service
   - Connect GitHub repository
   - Name: acked-backend
   - Environment: Python 3
   - Root Directory: acked/

   Build Command:
   pip install -r requirements.txt && python manage.py collectstatic --noinput

   Start Command:
   gunicorn acked.wsgi:application --bind 0.0.0.0:$PORT

   - Plan: Free tier
   - Click "Create Web Service"
   - Wait for build (3-5 min)

4. ADD ENVIRONMENT VARIABLES
   - Go to Service Dashboard > Environment tab
   - Click "Add Environment Variable" 14 times

   Django (3):
     SECRET_KEY = [generate new one]
     DEBUG = False
     ALLOWED_HOSTS = acked-backend.onrender.com,localhost

   Database (6):
     DB_ENGINE = django.db.backends.postgresql
     DB_NAME = ackeddb
     DB_USER = ackeddb_user
     DB_PASSWORD = [from PostgreSQL]
     DB_HOST = dpg-xxxxxxxxxxxxx.render.com
     DB_PORT = 5432

   Cloudinary (3):
     CLOUDINARY_CLOUD_NAME = [from cloudinary.com]
     CLOUDINARY_API_KEY = [from cloudinary.com]
     CLOUDINARY_API_SECRET = [from cloudinary.com]

   Security (2):
     CORS_ALLOWED_ORIGINS = http://localhost:3000,https://your-frontend.vercel.app
     CSRF_TRUSTED_ORIGINS = https://your-frontend.vercel.app

   After adding: Service auto-redeploys

5. RUN MIGRATIONS
   - Go to Service Dashboard > Shell tab
   - Click "Connect"
   - Type: python manage.py migrate
   - Wait for completion

6. TEST
   - Visit: https://acked-backend.onrender.com/shop/categories/
   - Should see JSON data
